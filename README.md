## Hi, I'm Pranav 👋

I build projects that turn data into something people can use: a sentiment dashboard, a fraud score, an inventory workflow, or an AI assistant for business operations.

My focus is **data science and analytics**, connected to the APIs, databases, and interfaces that make an idea usable. This GitHub is my learning lab—from small browser apps to larger systems with access control, background jobs, and local AI.

## Latest in the lab

- **October 2026 · [Dynamic Authentication](https://github.com/Shadow-Pranav/Dynamic_Authentication)** — starting a Zero Trust Dynamic Authentication project with draft API contracts, trust-tier policies, and React/TypeScript tooling. **Early scaffold; the application is still to be built.**
- **September 2026 · [CG Foods Sentiment Analysis](https://github.com/Shadow-Pranav/CG_Foods_Sentimental_Analysis)** — a sentiment pipeline with VADER and multilingual transformers, event analysis, interactive filters, and PDF reports. The default demo uses **synthetic data**.
- **August 2026 · [SITS Inventory](https://github.com/Shadow-Pranav/Inventory-Management-System)** — rebuilt around Django and PostgreSQL, with organization isolation, inventory models, and role-based administration. Catalogue workflows are the next development phase.
